Welcome! This is a personal blog built with [Astro](https://astro.build/) and the [AstroPaper](https://github.com/satnaing/astro-paper) theme.

## Start Writing

Create a new Markdown file under the `src/data/blog/` directory to publish a post.

### Post Format

```markdown
---
title: "Post Title"
description: "Post description"
pubDatetime: 2026-05-13
tags: ["tag"]
---

Content...
```

### Custom Configuration

You can edit `src/config.ts` to adjust the site title, description, social links, and more.

## Features

- Responsive design for mobile and desktop
- Dark/light mode toggle
- SEO friendly
- Post search
- RSS feed

## Deployment

Push to GitHub and GitHub Actions deploys the site to GitHub Pages automatically.

Happy writing!
