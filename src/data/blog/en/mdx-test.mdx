This post verifies that the blog's MDX support works correctly. MDX allows mixing JSX syntax into Markdown content.

## Standard Markdown

MDX is fully compatible with standard Markdown syntax: **bold**, _italic_, `inline code`, and [links](https://astro.build/).

## Variables and Expressions

MDX lets you define variables below the frontmatter and reference them in the content:

export const siteName = "My Blog";
export const year = new Date().getFullYear();
export const posts = ["Hello World", "MDX Test", "Astro Guide"];

Current site: **{siteName}**, current year: **{year}**.

export const product = 2 * 3;

Math operations: 2 × 3 = {product}, and the array length is {posts.length}.

## Conditional Rendering

export const showAdvanced = true;

{showAdvanced ? (

  <div style={{ padding: "1rem", border: "1px solid var(--color-border)", borderRadius: "8px", margin: "1rem 0", color: "var(--color-foreground)" }}>
    <strong>Advanced content enabled</strong> — this block is rendered through a JSX conditional.
  </div>
) : (
  <p>Advanced content is hidden.</p>
)}

## List Rendering

Generate lists dynamically with JSX `map`:

<ul style={{ paddingLeft: "1.5rem" }}>
  {posts.map((post, i) => (
    <li key={i}>
      {i + 1}. {post}
    </li>
  ))}
</ul>
